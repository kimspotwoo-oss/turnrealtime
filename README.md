# turnrealtime

동시 실행형 턴제 전략게임. 모든 부대가 준비기간에 받은 명령에 따라 실행기간 동안 동시에 움직인다.

- 엔진: Godot 4.3
- 기획서: [동시 실행형 턴제 전략게임 기획서](https://claude.ai/artifact/DoueKpfjDjGDbMTPyE4fTB)

## 구조

- `sim/`: 화면과 상관없는 전투 계산. 칸 맵, 1초 틱, 이동, 시야, 사격, 관통·도탄, 흩어짐, 근접전, 제압·사기, 승리 조건.
- `sim/front_line.gd`: 전선 기능 (전선 긋기, 공세선, 후퇴선, 전선 태세, 예비대).
- `sim/defense_ai.gd`: 방어 AI. 자기 진영이 본 적만 보고, 플레이어와 같은 명령만 쓴다.
- `data/unit_types.json`: 1단계 병과 수치 (기획서 '1단계 병과 수치 초안').
- `data/stages/`: 스테이지 파일. 스테이지는 코드가 아니라 데이터다.
- `sim/orders.gd`: 준비기간 명령 (이동, 태세, 대형, 후퇴지, 포격, 전선 긋기·공세선·후퇴선·예비대).
- `scenes/main.tscn`, `scripts/battle_screen.gd`: 집중전투 화면. 부대는 NATO 부대 기호(`scripts/unit_symbol.gd`)로 그린다.
- `assets/fonts/`: 한글 글꼴 Pretendard (SIL Open Font License 1.1, `OFL-Pretendard.txt`).
- `tests/`: 헤드리스 테스트.

## 실행

Godot 4.3에서 프로젝트를 열고 실행(F5)하면 연습 스테이지가 뜬다.

- 왼쪽 클릭: 부대 고르기 (Shift: 더하기, 두 번 클릭: 같은 종류 모두), 빈 땅에서 왼쪽 끌기: 범위 선택
- 오른쪽 클릭: 이동 (Shift: 경유점, Ctrl: 후진), 적에 오른쪽 클릭: 가장 빠른 길로 다가가 최대 사거리에서 공격
- 오른쪽 끌기: 대형 배치 (선 길이 = 폭, 왼쪽에서 오른쪽으로 그으면 위쪽이 정면)
- 아군 부대에서 왼쪽 끌기: 경로 그리기 (적 위에서 놓으면 우선 사격)
- 부대 하나를 고르면 이번 턴에 닿는 범위가 흰 테두리로 보인다
- 부대를 고르면 바로 옆에 명령 창이 뜬다: 전력·사기 막대, 태세, 이동·후진·방향·정지 등
- 부대 기호 아래 막대가 남은 전력이다 (초록 → 노랑 → 빨강, 전차·포는 한 대에 한 칸)
- 부대 하나를 고르면 노란 테두리가 시야 범위, 파란 원이 사거리, 흰 칸이 이번 턴 이동 범위다 (V: 시야 켜고 끄기)
- 가운데 끌기: 화면 이동, 휠: 확대·축소
- 터치: 누르기 = 선택, 부대에서 끌기 = 경로, 빈 땅 끌기 = 화면 이동, 두 손가락 = 확대·축소. 이동·후진·대형 배치는 오른쪽 단추로
- "난이도" 단추: 쉬움 · 보통 · 어려움 (첫 턴 전에만 바꿀 수 있고, 바꾸면 전투를 처음부터 다시 연다)
- 스페이스 또는 "실행 ▶": 실행기간 1턴, 실행 중에는 일시정지
- 1~4: 태세, M 이동, R 후진, F 방향, G 대형 배치, S 정지, Tab: 다음 부대, Ctrl+A: 모두, O: 모든 부대 명령 보기
- Enter: 선 그리기 마치기, Esc: 취소, F1: 적 전체 보기 (시험용)

테스트:

```sh
godot --headless --import
godot --headless -s tests/run_tests.gd
```
